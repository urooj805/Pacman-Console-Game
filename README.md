# Pac-Man Game (Console-Based in C++)

A console-based implementation of the classic Pac-Man arcade game.  
Players navigate the maze, collect points, avoid ghosts, and aim for the highest score.

## File Structure
- `src/` : C++ source files
- `data/` : Game data files (maze, high scores)
- `extras/` : Demo video
- `docs/` : Project documentation (pacman.pdf)
- `README.md` : Project overview

## Features
- Random ghost movements
- Collision detection
- Score tracking and high-score updates
- Quit option anytime

## How to Run
1. Clone the repository
2. Navigate to the `src/` folder
3. Compile the source files using a C++ compiler
4. Run the program in the console
